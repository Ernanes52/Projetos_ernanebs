# Instruções do projeto

## Fluxo Git após alterações

Sempre que concluir uma alteração ou criação de código neste projeto:

1. Execute `git status` para revisar o estado do repositório.
2. Execute `git add .` para preparar as alterações.
3. Faça um commit com uma mensagem clara, em português, descrevendo o que foi feito.
4. Execute `git push` para enviar o commit ao GitHub.

Antes de efetuar o commit e o push, confira o resultado de `git status` e não inclua arquivos não relacionados ao trabalho. Se o commit ou o push falhar, informe o erro e não afirme que as alterações foram enviadas.
